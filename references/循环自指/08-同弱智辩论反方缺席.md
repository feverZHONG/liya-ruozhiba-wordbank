# 同弱智辩论反方缺席

## 来源

本次弱智吧批量题。

## 原问题

「正方以『应该同弱智辩论』为辩题大获全胜，只因反方全部缺席。」

## 谬误类型

**循环自指** — 辩题本身决定了反方不会来，因为来的人就不是弱智。

## 拆解

| 角色 | 辩题 | 实际情况 |
|------|------|---------|
| 正方 | 应该同弱智辩论 | 正方在场，准备辩论 |
| 反方 | 反对「应该同弱智辩论」 | 反方缺席 |
| 原因 | — | 反方如果是弱智→不会来参加辩论 |
| | | 反方如果不是弱智→不是正方要辩论的对象 |

辩题是「应该同弱智辩论」。反方如果真是弱智→他们不会来参加辩论。反方如果不是弱智→他们不是正方要辩论的对象（正方要辩论的是弱智）。无论怎样反方都来不了。

## 怎么解才不会掉坑

**一句话：** 辩题本身就把反方赶走了——弱智不会来，非弱智不是对手。正方不战而胜。

**正确解法：** 指出辩题的定义决定了反方无法到场。

**常见死法：** 讨论辩论赛的规则——段子玩的是自指悖论，不是竞赛规程。

## 防御

> 「那『应该同哑巴辩论』——反方来了，全程沉默，赢了还是输了？」
