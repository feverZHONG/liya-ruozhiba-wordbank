# 38分改88分——父亲为什么崩溃

## 来源

经典逻辑陷阱/反转故事。

## 原问题

「女孩数学38分改成88分。父亲看到试卷大怒：『这8怎么一半绿一半红，你以为我是傻子？』打了她一巴掌。过了一会儿父亲突然崩溃了。为什么？」

## 谬误类型

**伪前提 + 认知陷阱** — 先入为主的解释跳过了所有其他可能性。

## 怎么解才不会掉坑

**一句话：** 父亲也是红绿色盲。他看出颜色不一样不是「看到」的，是推理出来的——但他不该推理出这个结果。

**正确解法：**

逻辑链：
1. 女儿改分数用的是不同颜色的笔——但她看不出颜色不同（她是色盲）
2. 父亲一眼看出「一半红一半绿」→ 说明他也能看出颜色差异
3. 红绿色盲是X连锁隐性遗传 → 女儿有，父亲必然也有
4. 他冷静下来想：不对，我怎么能看出哪个是红哪个是绿？→ 我也是色盲
5. → 我打了不该打的人，我这一辈子的颜色认知都是错的

**常见死法：** 纠结「父亲到底怎么看出颜色的」——答案不在「他怎么看出来」，而在「他为什么能推理出这个结论」。他以为是亲眼所见，其实是他潜意识里知道试卷分数是红笔写的、涂改是绿笔写的，然后「推理」出了那个8的颜色分布——但他自己没意识到这是推理，以为是直接看到的事实。

## 防御

> 「他能说出来→说明他也能分→红绿色盲遗传→他也是。他崩溃的不是打了女儿，是他一辈子看到的红绿全是错的。」
