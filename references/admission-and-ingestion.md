# 题库入库标准与流程

> 从 SKILL.md 拆出（2026-09-04 拆薄）。入库时用，防御时不用看。

## 入选标准

不是所有弱智吧段子都值得入库。能进武器库的只有**逻辑陷阱**，不是**段子合集**。

### ✅ 入库标准（至少满足两条）

| 标准 | 说明 |
|------|------|
| **有明确谬误类型** | 能归入六类之一：范畴谬误/偷换概念/循环自指/伪前提/反向释义/假类比 |
| **有可拆逻辑链** | 能说清楚「前提怎么错了」「概念在哪偷换了」「循环在哪」 |
| **有防御价值** | 有人可能会拿这个来问 AI——不是只存在于纸面上的段子 |
| **适合一句话反杀** | 能用一句防御话术结束战斗，不需要长篇大论 |

### ❌ 不入库的

| 类型 | 例子 | 原因 |
|------|------|------|
| 纯反转段子 | 「院长吃了麻婆豆腐被麻婆砍了二十多刀」 | 只有情节反转，没有逻辑可拆 |
| 纯谐音梗 | 「私密马赛」「东坡肉跳苏轼圈」 | 只有发音巧合，谬误不独立 |
| 诗意/哲思金句 | 「开关是灯的日出日落」 | 是诗不是陷阱，不需要防御 |
| 冷门梗 | 需要特定背景知识才懂的 | 贴吧来人不会拿这个来问你 |
| 纯恶心/敏感 | 涉及极端血腥/政治敏感 | 不出题也不回答 |

### 状态标记

入库时在文件末尾标注状态：

- `status: active` — 已完整可用的题
- `status: pending` — 待实测/待补充
- `status: reference` — 仅作知识参考，不出题

## 从长文章拉题目时：确认拿到了全文再动手

（2026 会话踩坑）拉知乎21周年文章的100条段子，API 只返回前 25 条摘要就以为够了，实际后面还有 75 条：

- API/summary 字段返回的内容如果长度恰好是一个整数（如1053字符），大概率是截断了
- 先检查返回长度预期：100条段子不可能只有1000字
- 拿不到全文时直接问用户，不将就着半截数据筛题
- **宁可只入库确认完整的题目，也不基于半截内容出题**
